# v0.4.3 — Stable release

Windows Image Search v0.4.3 adds the supplied application artwork as the Windows app icon and an About window.

## Highlights

- Uses the exact supplied artwork for the app/window icon and embeds a multi-size Windows icon (16 through 256 px).
- Adds an About window to the main menu with links to [emadghasemi.ir](https://emadghasemi.ir) and the [GitHub repository](https://github.com/emadgh/windows-image-search).
- Keeps the v0.4.2 features: Everything filename search, clipboard image search, responsive Grid sizing, scoped rescans, bounded previews, and face/People search.
