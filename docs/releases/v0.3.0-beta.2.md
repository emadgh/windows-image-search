# v0.3.0-beta.2 — Beta, validation incomplete

**This is a beta prerelease for testing. Tests are not final and this release has not completed production acceptance.**

**این نسخه بتا و برای آزمایش است. تست‌ها نهایی نیستند و تأیید نهایی کیفیت و رابط کاربری هنوز انجام نشده است.**

## Changes

- Added bounded libvips decoding for memory-unsafe PNG and TIFF sources while retaining the scaled JPEG decoder.
- Packaged the complete libvips 8.18.6 Windows runtime beside the executable in the release ZIP.
- Preserved existing portable thumbnails and legacy-cache recovery; cached thumbnails are used before attempting a new large-image decode.
- Added bounded on-demand preview generation and atomic thumbnail/preview cache writes.
- Registered roots whose drive or folder is unavailable are reported clearly, excluded from image/search/preview lists, and retained for recovery when the drive is reconnected.
- Kept the existing portable index and database contracts unchanged.

## Validation and known limitations

- Local validation: formatting check, all-target tests with and without libvips, and optimized Windows Release build passed.
- Windows build #725 passed the default and libvips checks, benchmark regressions, complete runtime packaging, and packaged executable smoke test.
- Issue 225 validation #12 passed orientation, libvips PNG/TIFF, decode-failure, and packaging-related checks.
- The release is a beta. Manual UI acceptance and labeled material/face quality datasets are still pending.
- A disconnected registered root remains in the database by design; its images are hidden until the same drive/path is available again.

Private images, databases and model weights are not included in the release.
