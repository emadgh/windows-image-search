# v0.4.4 — Stable release

Windows Image Search v0.4.4 adds folder navigation and persistent view preferences.

## Highlights

- Browse indexed folders and collections in a compact, virtualized tree in the search sidebar. Unavailable registered folders remain visible.
- Select a folder to scope Grid, Details, text, similar-image, description, and face results. Folder scopes combine with collection, people, and color filters.
- Configure subfolder inclusion, automatic search reruns, and selected-file navigation and highlighting under **Settings → Folders & Collections**.
- Selecting a result can expand and scroll the tree to its folder without changing the active search scope.
- Restore view preferences across restarts, including Inspector visibility, thumbnail size and fit, Grid/Details mode, sorting, appearance, panel widths, and window size/state.
- Draw interface icons with vector shapes so plus, minus, navigation, and sort indicators render consistently without missing-font boxes.
