# v0.4.1 — Stable release

Windows Image Search v0.4.1 is a maintenance release focused on faster visual-search workflows and more predictable library management.

## Highlights

- Paste an image with Ctrl+V from anywhere in the app to start visual similarity search; text paste remains unchanged.
- Responsive Grid sizing chooses the nearest thumbnail size that keeps complete columns in the available viewport.
- Collection and folder-level rescans reconcile only the selected scope, without rescanning unrelated library roots.
- Retains the bounded libvips previews, unavailable-file filtering, Collections management, preview navigation, and face/People search from v0.4.0.

## Validation

- `cargo fmt --all -- --check`
- `cargo check --all-targets --locked`
- `cargo test --all-targets --locked`
- `cargo build --bin windows-image-search`
