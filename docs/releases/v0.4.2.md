# v0.4.2 — Stable release

Windows Image Search v0.4.2 adds a shortcut from image results to Everything.

## Highlights

- When Everything is installed, file context menus include **Search by Everything**.
- Click the option to search the complete filename; Ctrl+click to search the longest number in the filename, such as `294918522` in `shutter_294918522.jpg`.
- Keeps the v0.4.1 features: clipboard image search, responsive Grid sizing, scoped collection/folder rescans, bounded previews, and face/People search.
