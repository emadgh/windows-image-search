# v0.4.0 — Stable release

Windows Image Search v0.4.0 is the first stable release of the current local-first image library and visual search workflow.

## Highlights

- Bounded libvips decoding for very large PNG and TIFF sources, with the existing scaled JPEG path retained.
- Complete libvips 8.18.6 Windows runtime packaged beside the executable.
- Portable per-root thumbnails, on-demand bounded previews, legacy-cache recovery, and atomic cache writes.
- Missing drives, folders, and source files are excluded from Grid, Search, filters, watcher updates, and previews while their database records remain recoverable.
- Collections management with folder/file assignments, collection-scoped filtering, and detailed index statistics.
- In-app whole-image preview with Space and left/right result navigation, plus the Shift+Space Inspector sidebar.
- Hybrid image similarity using color, texture, CLIP, and dominant-color signals.
- Paste an image with Ctrl+V from anywhere in the app to start visual similarity search; text paste remains unchanged.
- Responsive Grid sizing that chooses the nearest thumbnail size which keeps complete columns in the available viewport.
- Collection and folder-level rescans with scoped stale-path reconciliation, without rescanning unrelated library roots.
- Face search, People grouping, naming, merging, and per-face corrections.
- Duplicate review with full-file hashes and approximate visual groups without automatic deletion.

## Validation

- Formatting and the complete locked test suite passed locally.
- The optimized Windows release build passed and starts successfully with `--version`.
- Windows CI passed the default build, libvips configuration, bounded PNG/TIFF, JPEG orientation, decode-failure, packaging, and smoke-test checks.
- Issue #225 acceptance validation passed for bounded previews, orientation handling, corrupt-input behavior, and runtime packaging.
- The unavailable-file regression test confirms that applying filters cannot reintroduce deleted or inaccessible indexed paths.

The application keeps source images, portable indexes, and databases separate from the release bundle. Private images, databases, and model weights are not included.
