# v0.3.0-beta.1 — Beta, validation incomplete

**This is a beta prerelease for testing. Tests are not final and this release has not completed production acceptance.**

**این نسخه بتا و برای آزمایش است. تست‌ها نهایی نیستند و تأیید نهایی کیفیت و رابط کاربری هنوز انجام نشده است.**

## Changes

- Redesigned Collections with three columns: navigation, Contents, and Settings/Statistics; left-aligned collection rows and selectable folders.
- Background statistics scoped to a collection or folder: indexed/discovered images, thumbnail files, CLIP embeddings, face records/embeddings, descriptors, formats, sizes and decode failures.
- Cancellable image/text/region search, search presets, duplicate review, people backup/undo/offline synchronization, and bounded descriptor caching.
- Isolated benchmark workspaces, accurate provider/error reporting, small-vector-bank ANN fallback and detailed validation reports.

## Validation and known limitations

Automated regressions cover collection/folder count boundaries, deduplication, missing databases, partial face statistics, unchanged fixture database/cache bytes, and sidebar text alignment. The release workflow runs all Rust targets before packaging. Successful automated checks do not replace manual UI or search-quality acceptance.

Local beta validation: formatting check and all-target Rust tests passed (260 application tests plus 5 repair tests, 265 total).

- Manual acceptance of the redesigned UI is still pending.
- Independent different-photo/same-material labels and labeled identity/detection datasets are missing; quality and thresholds are not finally approved.
- DirectML initialization failed on the evaluated host. Four alternative image-model downloads failed; GPU/model comparison is incomplete.
- Large-bank ANN candidate API performance remains slower than exact scanning in the measured scenario.
- Statistics count saved records and existing source-keyed thumbnail files. They do not certify model freshness or thumbnail decoding; unavailable portable indexes are reported as partial results.

See [validation report](https://github.com/emadgh/windows-image-search/blob/v0.3.0-beta.1/docs/validation-2026-09-06.md) and [statistics definitions](https://github.com/emadgh/windows-image-search/blob/v0.3.0-beta.1/docs/collection-statistics.md). Issues #28, #29, #30, #32, #62 and #69 remain open for their unmet acceptance gates. Private images, databases and model weights are not included in the release.
