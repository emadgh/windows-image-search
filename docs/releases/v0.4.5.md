# v0.4.5 — Stable release

## Faster startup

- Reuse the local SQLite catalog for unchanged portable indexes. The first launch after upgrading may import them once to establish their revisions.
- Check for missing files and audit People data in the background. Prepare the visual similarity index when a search needs it.
- Record startup stage timings in `startup-profile.txt` beside the local catalog. Compare `catalog_ready_ms` after a second launch to measure catalog startup.

## Browsing and opening images

- Keep keyboard selection in view while navigating Grid and Details.
- Scroll the folder tree to the focused image's folder and briefly highlight it when enabled.
- Open selected images in their default app or Photoshop. The native Windows context menu supports multi-selection within one folder.
- Save Inspector visibility immediately and restore it on startup. It defaults to closed until a preference is saved.
